# Antrenman Takip

GitHub Pages için hazırlanmış mobil antrenman takip uygulaması.

## GitHub Pages kurulumu

1. Bu ZIP içindeki dosyaları GitHub deposunun ana dizinine yükleyin.
2. GitHub'da **Settings > Pages** bölümünü açın.
3. **Deploy from a branch** seçeneğini seçin.
4. Branch olarak **main**, klasör olarak **/(root)** seçin ve kaydedin.
5. GitHub'ın oluşturduğu HTTPS adresini iPhone Safari veya Samsung Internet/Chrome ile açın.

## Ana ekrana ekleme

- iPhone: Safari > Paylaş > Ana Ekrana Ekle
- Samsung: Tarayıcı menüsü > Ana ekrana ekle / Uygulamayı yükle

## Önemli

Kayıtlar her cihazın kendi tarayıcısında saklanır. Cihazlar arasında taşımak için uygulamadaki JSON dışa aktarma ve Girdi Yükle seçeneklerini kullanın.
